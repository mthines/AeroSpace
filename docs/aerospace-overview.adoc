:manname: aerospace-overview
// tag::purpose[]
:manpurpose: Show a Mission Control-style overview of selected workspaces
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospace overview [--suspend|--resume]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

When invoked, selected workspaces' windows are physically repositioned into a
grid on the active monitor. Each cell shows a workspace's actual live windows
rendered natively. A dimming overlay appears behind the repositioned windows.

Use arrow keys or hjkl to navigate between workspace cells, Enter to switch
focus to the selected workspace, or Esc to close the overview without changing
focus. All windows are restored to their exact original positions when the
overview closes.

Configure the command with the `[overview]` block in your config file.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help

--suspend:: Pause the overview without tearing it down: hide the HUD and dim
panel, restore window frames, and keep the anchor monitor and snapshot state.
Use before switching to a non-grid workspace (e.g. a scratchpad) so the next
`--resume` can re-establish the same grid. No-op when the overview is closed
or already suspended.

--resume:: Re-establish a suspended overview on its original anchor monitor.
Windows are re-snapshotted so any moves made while suspended are reflected.
No-op when the overview is not suspended.

`--suspend` and `--resume` are mutually exclusive.

// end::body[]
